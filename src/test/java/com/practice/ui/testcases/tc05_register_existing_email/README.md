# Test Case 05: Register User with existing email

**Source:** https://automationexercise.com/test_cases (Test Case 5)

## Description
Verify error when attempting to register with duplicate email.

## Preconditions
An account with the email address used in step 6 must already exist.

## Test Steps
1. Launch browser
2. Navigate to url 'http://automationexercise.com'
3. Verify that home page is visible successfully
4. Click on 'Signup / Login' button
5. Verify 'New User Signup!' is visible
6. Enter name and already registered email address
7. Click 'Signup' button
8. Verify error "Email Address already exist!" is visible
